# AirSense India — Air Quality Prediction System

A full-stack air quality analysis and prediction application built entirely in Python,
using a **Random Forest** machine learning model, a **Flask REST API** backend,
and a **Streamlit** multi-page frontend.

---

## Dataset

| File | Description |
|---|---|
| `city_day.csv` | Daily AQI + 12 pollutants for 26 cities |
| `city_hour.csv` | Hourly readings |
| `station_day.csv` / `station_hour.csv` | Station-level data |
| `stations.csv` | Station metadata (name, city, state) |

**Key columns:** `PM2.5`, `PM10`, `NO`, `NO2`, `NOx`, `NH3`, `CO`, `SO2`,
`O3`, `Benzene`, `Toluene`, `Xylene`, `AQI`, `AQI_Bucket`

---

## Machine Learning Model

| Property | Value |
|---|---|
| Algorithm | Random Forest (scikit-learn) |
| Regressor R² | **0.91** |
| Regressor MAE | **~21 AQI units** |
| Classifier Accuracy | **81 %** |
| Features | 12 pollutant concentrations |
| Targets | AQI (regression) + Bucket (classification) |

AQI Buckets: `Good → Satisfactory → Moderate → Poor → Very Poor → Severe`

## Setup & Run

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the model (one-time)

```bash
python train_model.py
```

This creates the `models/` folder with all saved artefacts.

### 3. Start the Flask API (Terminal 1)

```bash
python app.py
```

API will be live at `http://127.0.0.1:5000`

### 4. Start the Streamlit frontend (Terminal 2)

```bash
streamlit run streamlit_app.py
```

Opens at `http://localhost:8501`

> **Note:** The Streamlit prediction page falls back to loading models locally
> if the Flask API is not running, so you can use the frontend standalone too.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/health` | Liveness check |
| GET | `/api/cities` | List all 26 cities |
| GET | `/api/city_defaults/<city>` | Median pollutant values for a city |
| POST | `/api/predict` | Predict AQI + bucket from pollutants |
| GET | `/api/city_trend/<city>` | Historical AQI data for a city |
| GET | `/api/summary` | Overall dataset statistics |

**POST `/api/predict` example:**

```json
{
  "PM2.5": 120.5, "PM10": 200.0, "NO": 30.0, "NO2": 45.0,
  "NOx": 80.0, "NH3": 12.0, "CO": 5.5, "SO2": 22.0,
  "O3": 40.0, "Benzene": 3.2, "Toluene": 8.1, "Xylene": 2.0
}
```

**Response:**

```json
{
  "aqi": 287.4,
  "bucket": "Poor",
  "colour": "#ff7c00",
  "confidence": 74.2,
  "advice": "Everyone may begin to experience health effects. Reduce outdoor activity."
}
```

## App Pages

### Home (`streamlit_app.py`)
- National KPIs: total records, avg AQI, cities, date range
- Monthly AQI trend line (2015-2020) with category bands
- AQI bucket distribution donut chart
- Average AQI bar chart ranked by city

### EDA (`pages/1_EDA.py`)
- Pollutant correlation heatmap
- AQI distribution box plots by city
- Pollutant vs AQI scatter with OLS trendline
- Seasonal (monthly) AQI pattern
- Year-over-year AQI comparison
- Missing data overview

### Prediction (`pages/2_Prediction.py`)
- City defaults loader (pre-fills sliders with city medians)
- 12 interactive pollutant sliders
- Instant AQI prediction via Flask API (local fallback if API is down)
- AQI gauge chart + bucket badge + health advice
- Input pollutant breakdown bar chart
- AQI reference scale

### City Trends (`pages/3_City_Trends.py`)
- Configurable rolling average (1–90 days)
- Optional city-vs-city comparison
- AQI timeline with category bands
- PM2.5 + PM10 dual-axis area chart
- Monthly heatmap (Year × Month)
- AQI bucket breakdown bar chart
- Normalised pollutant radar chart
- Raw data table export
